# AI Event Platform v2

A local college event platform combining personalized recommendations with a grounded event-information chatbot. This repository is being built in phases; this first phase provides the scaffold and reproducible synthetic data pipeline.

All generated users, events, friendships, and interactions are synthetic. To create the local data, run `make setup`, then `make data`. Later phases add model training, retrieval, the API, and the web app.

Current generated data is written to `ml/data/generated/` and the SQLite database to `event_platform.db` (both ignored by Git). Model artifacts are written to `ml/artifacts/` (ignored by Git).

## Baseline evaluation

The following baseline metrics were generated by `python -m ml.evaluation.run_experiments` on the synthetic data. Evaluation ranks up to ten events that are open at each held-out positive interaction time.

| Model | Queries | Recall@10 | NDCG@10 | HitRate@10 | Catalog coverage@10 |
|---|---:|---:|---:|---:|---:|
| Popularity | 1325 | 0.8792 | 0.4622 | 0.8792 | 0.1640 |
| TF-IDF KNN | 1325 | 0.9155 | 0.5255 | 0.9155 | 0.1680 |
| Matrix Factorization | 1325 | 0.8740 | 0.4251 | 0.8740 | 0.1640 |

Warm target results are unavailable: the test split has no warm targets. Events are open for at most 30 days, but test interactions begin 38 days after the training cutoff, so open test events were posted after the cutoff. Also, 39.4% of test queries have at most ten eligible candidates, which limits how informative Recall@10 is. See [`docs/results/results.md`](docs/results/results.md) for all segment tables and details; rerun `make eval` to regenerate them.
